# Template provenance

`Informatica2026.docx` is the journal's author-provided Word template downloaded from
https://www.informatica.si/public/site/Informatica2026.dotx on 16 November 2026.
Its OOXML main-content type was converted from template to document so python-docx can open it.
The journal-styled manuscript removes sample content and publication/acceptance placeholders;
it does not imply that the journal accepted or published the article.
